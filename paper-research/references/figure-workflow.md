# 论文原图提取与图解工作流

原图的作用是降低理解成本并提供可追溯证据，不是装饰。通常每篇保留 1–3 张最有解释力的图：一张方法/研究设计图，加一张关键结果、消融或失败案例图；没有合适图时不凑数。

## 1. 建立图像候选清单

先读正文中的 Figure 引用和 caption，记录：

| 字段 | 内容 |
|---|---|
| `figure_id` | Figure 1 / Fig. 3 / 原文图号 |
| `pdf_page` | 实际 PDF 页序 |
| `paper_page` | 论文印刷页码（如不同） |
| `caption_summary` | 图注的忠实概括 |
| `purpose` | 方法总览/结果/消融/定性/失败案例 |
| `crop` | 页面裁剪坐标或提取对象 |
| `output` | 最终文件名 |

优先级：

1. 能解释整篇方法、论证或数据构建的总览图。
2. 支持核心证据表重要结论的结果图。
3. 揭示组件作用的消融/敏感性图。
4. 揭示适用边界的失败案例或定性图。

Logo、作者头像、装饰图、重复子图、不可读缩略图和不参与分析的图片不进入最终目录。

## 2. 提取策略

按可靠性从高到低选择：

1. **页面局部渲染/裁剪**：对矢量图、组合图和表格最稳妥；保留完整图例、坐标轴和必要 caption。
2. **PDF 对象提取**：适合完整内嵌位图；检查是否只得到背景、蒙版或碎片。
3. **整页渲染**：仅当无法可靠裁出图，且整页本身对理解确有必要；在图解中说明。

推荐工具：

- `pdftoppm` 渲染指定页。
- `pdfplumber`/`pypdf` 提取文本并定位页码。
- `PyMuPDF` 可用时提取对象或裁剪；不可用不应成为阻塞条件。
- 扫描件可使用 OCR 辅助定位，但图号和正文仍需视觉核对。

优先使用当前环境已有工具或项目虚拟环境。不要为一次可降级的提图任务隐式修改全局 Python 环境。

## 3. 临时与最终目录

```text
/tmp/paper-research/<run-id>/
├── rendered-pages/
├── extracted-objects/
├── crops/
└── figures-manifest.json

论文/images/<note-stem>/
├── fig-01-method-overview.png
└── fig-04-main-results.png
```

- 临时目录按 run 隔离。
- 最终目录只包含已筛选、已核对、实际被笔记引用的图片。
- 只清理 manifest 明确登记为本次创建的临时文件；不要删除已有用户资产。

## 4. 命名规则

使用：`fig-<两位图号>-<lower-kebab-semantic>.png`。

示例：

- `fig-01-method-overview.png`
- `fig-03-retrieval-pipeline.png`
- `fig-05-ablation-results.png`
- `fig-07-failure-cases.png`

若原文图号带字母，可用 `fig-03a-*`。文件名表达真实图意，不用 `image1.png`、`page4.png` 或模型猜测出的名称。

## 5. 裁剪与质量

1. 以 160–220 DPI 渲染作为常用起点；小字密集图可提高分辨率。
2. 裁剪保留所有子图标签、图例、坐标轴、单位和必要边界。
3. 不把原论文图中的局部重新拼接成会改变语义的新图。
4. 不做会改变数据含义的增强；可做无损裁剪和必要的白边整理。
5. 打开最终 PNG 检查：文字可读、无黑块/透明蒙版错误、方向正确、图号对应。

视觉检查不能只看文件存在或分辨率；至少查看每张最终图一次。

## 6. Markdown 嵌入与图解

从 `AI分析/<note>.md` 指向图片通常使用：

```markdown
![图 2：方法总体架构](../images/Paper/fig-02-method-overview.png)

*图 2（原文 Figure 2，PDF p. 4）：方法总体架构。*

1. **先看什么**：输入、图例、颜色或坐标轴分别表示什么。
2. **关键机制/趋势**：沿箭头或坐标轴解释主要信息。
3. **与正文结论的关系**：该图支持哪条主张，证据边界是什么。
```

图注是忠实概括，不要把原文 caption 大段逐字复制。结果图必须解释指标方向和设置；架构图必须解释输入、数据流、训练信号和输出。

## 7. 无图与材料受限

保留 `# 关键原图与图解` 标题，并明确写原因：

- `当前只有摘要，无法可靠获取原论文图。`
- `论文以文本/定理为主，未发现对理解有实质帮助的图；关键论证见原文 §...。`
- `PDF 中关键图无法在当前环境可靠提取；已根据原文 §... 用文字说明，未自行重绘。`

不要用 Mermaid、AI 生成图或凭正文重画来冒充原论文图。只有用户明确要求“另画解释图”时才可单独生成，并醒目标为“解读示意，非原论文图”，不能替代本节的原图证据。

## 8. 图像验收

- 图片路径从 Markdown 文件位置解析后存在。
- alt 文本准确且非空。
- 文件名与图号/语义一致。
- 图下标明原文 Figure 和 PDF 页码；无法获得某项时说明。
- 图解包含读图顺序、关键信息和证据边界。
- 最终目录没有未引用的临时碎片。
- 论文身份、图像内容与笔记相匹配；不能串图。
