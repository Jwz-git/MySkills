# Paper Research Workflow

## 概述

本技能提供从论文检索到分析归档的完整闭环，通过 **Skill 工具显式调用** 以下现有能力：

| 能力 | 调用方式 | 用途 |
|------|---------|------|
| 学术论文检索 | arxiv-mcp (`search_papers`) 直接调用 | 按关键词/分类查找论文 |
| 论文下载与读取 | arxiv-mcp (`download_paper` / `read_paper`) 直接调用 | 获取全文内容 |
| PDF 文本提取 | `pdf` skill 或直接读取 | 补充文本提取（arxiv 未覆盖时） |
| **结构化分析报告** | **Skill 工具 → `paper-explanation` skill** | 生成深度分析笔记 |
| **格式标准化** | **Skill 工具 → `paper-notes-tidy` skill** | 统一 frontmatter、标签、链接 |

> **核心原则：必须通过 Skill 工具调用已有 skill，而非手动模拟其输出格式。** paper-explanation 和 paper-notes-tidy 已有完整的 SKILL.md 定义，本技能的工作是编排流程，在适当时机调用它们。

## 工作目录

本文档中所有路径均为**相对于知识库根目录的相对路径**（即当前工作目录）。如果你在项目的知识库根目录下工作，路径默认有效。

```
知识库根目录/                    # 当前工作目录或用户指定的知识库根目录
├── 论文/
│   ├── 论文原件/                # 存放下载的 PDF 原文
│   ├── AI分析/                  # 存放最终的结构化分析笔记 (*-analysis.md)
│   └── images/                  # 论文相关图片
```

如果用户的目录结构不同，请先让用户确认对应关系再执行。
│   ├── 论文原件/                # 存放下载的 PDF 原文
│   ├── AI分析/                  # 存放最终的结构化分析笔记 (*-analysis.md)
│   └── images/                  # 论文相关图片
```

## 核心工作流

### 阶段一：需求理解与检索规划

与用户确认以下信息，形成检索策略：

1. **研究主题与关键词** — 核心关注什么？
2. **过滤条件**：
   - 年份范围（如 2023-2025）
   - 论文类型（实验类/综述类/理论类）
   - arXiv 分类（如 cs.CV 计算机视觉、cs.LG 机器学习、cs.AI 人工智能、cs.CL 计算语言学、cs.RO 机器人学）
   - 会议来源偏好（如 CVPR, ICCV, NeurIPS, ICML, ACL, AAAI）
3. **数量目标** — 期望分析多少篇？（推荐 3-5 篇可深入分析）
4. **特殊要求** — 排除/侧重特定子方向、只关注有开源代码的论文等

> 如果用户一次性给的信息足够充分，可直接进入检索步骤，无需重复确认。

### 阶段二：论文检索与筛选

1. **构建检索 Query**：根据用户需求，设计 1-2 组检索式，覆盖不同角度：
   - 使用引号包裹精确短语：`"visual place recognition"`、`"low-rank adaptation"`
   - 组合概念：`"vision language model" AND "localization"`
   - 排除噪音：`"LoRA" ANDNOT "survey"`
   - 设置 arXiv 分类过滤，提升结果精准度

2. **执行检索**：使用 `search_papers`，关键参数：
   - `max_results: 15-20` — 获取足够候选
   - `sort_by: "relevance"` — 默认按相关性排序；调研最新进展时用 `"date"`
   - `categories` — 设置分类过滤

3. **初筛与排序**：对返回结果快速评估质量：
   - 检查标题与用户主题的匹配度
   - 获取摘要（`get_abstract`）评估内容相关性
   - 评估来源（arXiv 本身、疑似顶会投稿）
   - 多组检索结果合并去重

4. **用户确认**：呈现精选结果，每篇附标题、摘要片段、arXiv ID、初步质量判断，请用户选择感兴趣的论文。

### 阶段三：论文下载与转换

对用户确认的每篇论文：

1. **下载全文**：使用 `download_paper` 获取 PDF，记录 arXiv ID。
2. **读取正文**：使用 `read_paper` 获取论文的完整 markdown 文本。
3. **保存 PDF**：将 PDF 文件保存到 `论文/论文原件/` 目录：
   - 文件名使用英文 slug：以论文英文标题为基础，特殊字符替换为下划线
   - 例如：`GeLoRA_Geometric_Adaptive_Ranks_LoRA.pdf`
4. **补充提取**（如需）：如果 `read_paper` 返回的文本不够完整（如图表缺失、公式乱码），使用 `pdf` skill 的 `PdfReader` 或 `pdfplumber` 提取补充内容。

### 阶段四：结构化分析报告生成（Skill 调用）

对每篇论文，使用 **Skill 工具 → `paper-explanation`** 生成深度分析：

1. **调用方式**：使用 `Skill` 工具，`skill="paper-explanation"`，附上论文的 arXiv ID 或 PDF 路径或全文文本，让 paper-explanation skill 按自身模板生成报告。

2. **传入参数**：将论文的以下信息传给 skill：
   - arXiv ID（优先，skill 可自动获取全文）
   - 或本地 PDF 路径
   - 或传入 PDF 本地路径

3. **报告结构**（由 `paper-explanation` skill 自行保证）：
   ```
   # 一句话总结
   # 论文基本信息
   # 核心内容详解
   ## 1. 研究背景与问题
   ## 2. 方法方案
   ## 3. 实验/结果
   ## 4. 改进空间与展望
   # 流程图详解
   # 总结
   ```

4. **文件命名与保存**：
   - 文件名：`论文标题-analysis.md`（英文标题 slug + `-analysis` 后缀）
   - 保存位置：先暂存在工作区，后续阶段执行格式整理
   - 标题含不合法文件名字符（`/\\:*?"<>|`）时用短横线替换

5. **多篇并行处理**：多篇论文时可对每篇分别调用 paper-explanation 处理。

### 阶段五：格式标准化与归档（Skill 调用）

使用 **Skill 工具 → `paper-notes-tidy`** 对分析笔记进行格式标准化：

1. **调用方式**：使用 `Skill` 工具，`skill="paper-notes-tidy"`，指定需要整理的 MD 文件列表，让该 skill 按自身流程执行标准化。

2. **`paper-notes-tidy` 会处理以下内容**：
   - **Frontmatter**：确保 `title`, `date`, `tags`（`paper/xxx` 层级格式）, `aliases` 完整
   - **原文链接**：添加 `**原文**: [本地](论文/论文原件/文件名.pdf) [网络](https://arxiv.org/abs/XXXX.XXXXX)`
   - **Callout 标准化**：按标准使用 info, warning, success, note, abstract, tip, important
   - **标签层级**：扁平标签转为 `paper/xxx` 格式（如 `vlm` → `paper/vlm`）
   - **证据标注**：检查是否遗漏 `[证据: 来源]` 标注

3. **最终归档**：将整理完成的 `.md` 文件放入 `论文/AI分析/` 目录。

### 阶段六：汇总报告

所有论文处理完成后，生成汇总报告呈现给用户：

**检索概况**
- 本次检索的关键词与范围
- 共检索到 X 篇论文，精选分析 Y 篇

**论文列表**

| # | 论文标题 | arXiv ID | 核心方向 |
|---|---------|----------|---------|
| 1 | ... | ... | ... |

**方向概览**（多篇论文时）
- 各论文核心方法对比
- 各论文实验数据集/指标对比
- 论文间的关联与差异

## 优化拓展策略

### 批量处理

当用户要求分析多篇论文时：
1. 按主题相关性排序，优先处理最相关的论文
2. 每篇论文独立走完阶段三→四→五
3. 所有论文完成后再生成汇总报告

### 论文质量标签

在筛选阶段为候选论文附加质量标签：
- **高影响力**：引用量高、来自顶会/顶刊
- **新工作**：近 1-2 年发表，方法新颖
- **有代码**：论文提供开源代码，可复现
- **综述类**：系统梳理领域进展

### 对比分析

分析多篇同主题论文时，追加对比分析：
- 方法架构对比（可绘制 Mermaid 对比图）
- 性能数据对比表
- 创新点差异
- 适用场景建议

### 文献综述生成

用户选择"生成文献综述"时额外输出：
- 按时间线组织论文演进
- 归纳方法分类体系
- 指出研究空白与未来方向
- 输出为独立 MD 文件至 `论文/AI分析/` 目录

### 持续追踪

用户关注长期跟踪的主题时：
1. 使用 `watch_topic` 注册主题追踪
2. 告知用户可后续使用 `check_alerts` 检查新论文
3. 新论文自动进入分析流程

### 引用关系探索

使用 `citation_graph` 探索论文引用关系：
- 发现论文引用了哪些重要工作
- 哪些后续论文引用了本篇
- 构建研究脉络

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 检索结果太少（<3） | 放宽关键词或分类，扩大检索范围重新检索；若仍不足则分析已有论文并告知用户 |
| 检索结果过多 | 增加过滤条件，按引用/相关性排序取 Top-15 供用户选择 |
| 论文无法通过 arxiv 下载 | 说明无法下载的原因，提供 arXiv 链接建议用户手动获取 PDF |
| 论文正文超长（50页+） | 优先分析方法与实验章节，对相关工作与附录进行概括；报告开头标注"长篇论文，部分章节概括分析" |
| 仅能获取摘要 | 基于摘要生成初步分析并在报告中标注"[基于摘要分析]"，建议用户提供完整 PDF |
| 多篇论文同主题 | 逐篇生成独立分析报告，最后追加对比分析章节 |
| 用户未指定过滤条件 | 默认检索近 2 年论文（2024-2026），按相关性排序，结果偏多时请用户进一步指定 |
| 知识库目录不存在 | 询问用户知识库路径，或辅助创建标准目录结构 |

## Skill 调用速查

### 调用 `paper-explanation`

```markdown
<!-- 传入 arXiv ID（推荐，自动获取全文） -->
Skill tool: skill="paper-explanation"
args="分析 arXiv 2407.06730，这是检索下载的论文，PDF 已保存到本地，请生成分析报告"

<!-- 或传入 PDF 本地路径 -->
Skill tool: skill="paper-explanation"  
args="分析 论文/论文原件/xxx.pdf，生成结构化分析报告"
```

### 调用 `paper-notes-tidy`

```markdown
Skill tool: skill="paper-notes-tidy"
args="将 AI分析/ 目录下的 analysis.md 文件标准化 frontmatter、添加原文链接、整理标签为 paper/xxx 格式"
```

### 调用后处理

每次调用 skill 后，skill 的 SKILL.md 指令会加载到对话上下文。**等待 skill 完成输出后，再进行下一步。** 不要打断或跳过 skill 的自行输出。
