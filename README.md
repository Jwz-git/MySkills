# Skills

一组Skills，主要用于 Markdown 知识管理、论文笔记与图片转录。

## 包含内容

| Skill | 用途 |
| --- | --- |
| [`img2md`](./img2md/) | 将图片、截图和扫描件转写为 Markdown |
| [`knowledge-curator`](./knowledge-curator/) | 优先检索本地知识库，必要时补充外部资料并安全归档 |
| [`metadata-tidy`](./metadata-tidy/) | 审计和整理技术型 Markdown/Obsidian 知识库的 YAML frontmatter |
| [`paper-memory`](./paper-memory/) | 压缩、复习、关联、比较和更新学术论文笔记 |
