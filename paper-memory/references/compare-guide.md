# 论文对比指南

执行 `compare` 模式时使用本文档，用于评估和对比多篇论文。

## 1. 对比维度

先按 [paper-types.md](paper-types.md) 判断论文类型。两篇均为计算/ML 论文时，可按以下 13 个维度标准化评估：

1. **研究任务**：解决的具体问题。
2. **输入与输出**：训练和推理时的张量和模态。
3. **核心假设**：方法成功所依赖的前提条件。
4. **表示方式**：连续向量空间、体素网格、BEV 等。
5. **模型结构**：骨干网络选择、投影头、交叉注意力模块。
6. **训练目标**：具体的损失函数公式和优化目标。
7. **推理流程**：零样本评估、检索搜索或微调需求。
8. **数据集**：训练数据集和评估基准。
9. **评价指标**：准确率、召回率、F1、平均配准误差等。
10. **优势**：效率、精度、开放词汇能力、鲁棒性。
11. **局限**：失败场景、缺乏空间感知、数据饥渴。
12. **资源成本**：训练时间（GPU 小时）、显存占用、参数量。
13. **可迁移性**：适配到其他下游任务或模态结构的难易度。

---

## 2. 输出格式

对比输出保持以下章节；表格维度采用两篇论文都适用的集合：

```markdown
# 论文对比: Paper A vs. Paper B

## 1. 一句话区分
一句简洁有力的话总结两篇论文在方法或定位上的核心区别。

## 2. 共同点
列出共同的目标、架构或范式。

## 3. 关键差异对照
Markdown 表格。计算/ML 论文使用上述 13 维；其他论文使用 paper-types 中的共同维度。

## 4. 差异成因分析
解释*为什么*存在这些差异（如"Paper B 聚焦空间定位，因此增加了几何损失，而 Paper A 只关注语义检索"）。

## 5. 课题选择建议
结合用户研究方向，给出采用哪种方法（或组件）的具体建议。

## 6. 关系与知识库更新建议
按 profile 的平台和链接策略提出关系记录建议；未配置链接时只说明语义关系。
```

### Obsidian/Wiki Link 反向链接建议格式（仅在 profile 适用时）

```markdown
当前文件建议：
- 在本对比文件中建立指向 [[Paper A]] 和 [[Paper B]] 的链接。

反向更新建议：
- 在 [[Paper A]] 的「与其他论文的关系 - 关键差异」下添加：
  与 [[Paper B]] 的对比分析参见 [[Paper A vs Paper B]]。
- 在 [[Paper B]] 的「与其他论文的关系 - 关键差异」下添加：
  与 [[Paper A]] 的对比分析参见 [[Paper A vs Paper B]]。
```

## 3. 实验指标对比警告（关键）

> ⚠️ **不要在实验设置不同的情况下直接比较原始性能数字。**

如果样本/数据集、数据划分、测量方式、预处理、估计方法或评估框架不一致，必须明确声明：

> ⚠️ **注意：本对比涉及的实验指标设置不一致，指标数值不能直接用于判断方法优劣，仅供各自论文内部消融或对照参考。**

提供具体的设置差异细节（如"CLIP 使用 Prompt 模板在 ImageNet 验证集上评估零样本分类，而 DINOv2 使用冻结特征上的 k-NN 分类器评估零样本分类"）。
