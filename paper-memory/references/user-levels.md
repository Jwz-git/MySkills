# 用户熟悉度适配

仅在输出深度或复习难度无法从用户要求直接确定时使用。评估的是用户对“当前论文领域和方法”的熟悉度，不把其在一个领域的表现推广到另一个领域，也不必直接询问等级。

## 1. Beginner

信号：询问基础术语、研究问题或结论含义，尚未稳定掌握该领域的证据标准。

- 先解释研究问题和直觉，再引入术语。
- 只保留理解主线所需的公式、统计量、定义或材料细节。
- 解释作者为什么采用该方法，以及结论不能推广到哪里。
- 复习时接受不完整术语，但纠正会改变结论的概念错误。

## 2. Intermediate

信号：能够讨论方法环节、研究设计、证明步骤、数据/材料选择或定量结果。

- 明确输入材料、关键操作、输出结论和各环节依赖。
- 记录决定行为或结论的公式、假设、变量、引理或编码框架。
- 区分作者主张、证据实际支持的结论和替代解释。
- 复习时要求恢复具体步骤及关键条件。

## 3. Advanced

信号：主动讨论识别条件、因果声称、证明边界、选择偏倚、可复现性、反例或证据质量。

- 跳过领域常识，聚焦新颖性和真正改变结论的设计。
- 审查隐含假设、比较公平性、替代解释和外部有效性。
- 区分“结果与解释相容”和“解释已被证实”。
- 复习时要求提出反例、迁移条件或能区分候选解释的验证方案。

## 4. 各模式调节

| 内容 | Beginner | Intermediate | Advanced |
| --- | --- | --- | --- |
| 一句话记忆 | 问题、方法直觉、结论 | 任务、关键机制、作用 | 核心贡献及成立边界 |
| 方法流程 | 高层主线 | 关键步骤及输入输出 | 依赖关系、识别条件或证明转折 |
| 核心公式/命题 | 口头含义 | 变量/定义和作用 | 推导、敏感性及失效条件 |
| 证据理解 | 主要观察 | 设计、比较对象和指标 | 因果强度、偏倚和替代解释 |
| 关系链接 | 最直接关系 | 同问题与方法继承 | 冲突、互补和证据谱系 |
| 复习问题 | 主线恢复 | 机制与条件 | 批判、反例与迁移 |
