# 用户水平适配指南

使用本文档评估用户的专业水平，并动态调整输出的词汇、详细程度和讲解风格。不要直接询问用户的水平；应从其提示词中隐式推断。

## 1. 用户水平定义与画像

### 1.1 Beginner（初学者）
- **画像**：该特定研究领域或机器学习领域的初学者。可能对基础概念理解不够稳固。
- **特征指标**：询问基础术语（如 “什么是 embedding？”、“对比损失是如何工作的？”、“什么是 baseline？”）。
- **编写指南**：
  - **直觉优先**：在引入技术术语之前，先用现实生活中的类比来解释。
  - **减少公式**：限制数学公式的使用。如果必须使用，用通俗语言解释。
  - **解释专业术语**：立即定义任何特定领域的专业术语。
  - **着重强调“为什么”**：强调作者*为什么*这样解决问题，而不是解法的数学证明。

### 1.2 Intermediate（中级研究者）
- **画像**：理解主要概念和机器学习基础。专注于实现细节、模块设计和定量性能。
- **特征指标**：提及架构层、张量形状、训练时间、数据集划分或消融研究。
- **编写指南**：
  - **提供技术数据**：包含张量维度、输入输出映射和损失函数公式。
  - **对比训练与推理**：明确详述模型在训练和测试阶段行为的区别。
  - **专注于模块**：详细介绍核心模块如何交互，并分析它们的消融影响。

### 1.3 Advanced（高级研究者/专家）
- **画像**：在领域内非常有经验。对方法论持批判态度，专注于研究新颖性、实验严谨性和可复现性极限。
- **特征指标**：讨论因果声称、域偏移、训练稳定性、分布外泛化、数据泄露或超参数敏感性。
- **编写指南**：
  - **专注于边界**：突出方法失效的地方、隐含假设和局限。
  - **审视严谨性**：深度分析数据集构建偏差和基线对比的公平性。
  - **不提供基础解释**：跳过介绍性内容或对常见骨干网络（如 Transformer 或 ViT）的解释，专注于作者所做的自定义调整。

## 2. 水平推断与调节表

在生成总结或回答问题时，按下表调整重点：

| 章节 / 模式 | 初学者重点 | 中级重点 | 高级重点 |
| --- | --- | --- | --- |
| **一句话记忆** | 概念类比 | 目标任务与方法 | 范式转变与核心贡献 |
| **方法流程** | 高层框图 | 模态对齐与张量形状 | 数据流水线与因果依赖 |
| **训练目标** | 口头目标（“对齐特征”） | 损失公式与参数 | 梯度行为与稳定性问题 |
| **局限分析** | 显而易见的失败案例 | 计算与数据约束 | 归纳偏差与分布外 (OOD) 边界 |
| **复习提问难度** | 以概念回忆为主，接受模糊回答 | 要求具体的模块名称和张量维度 | 要求分析假设、边界条件和因果证据 |
| **关系链接深度** | 只建立最直接的 builds-on 关系 | 增加 same-task 和 similar-idea 关系 | 分析 contradicts、complements 等复杂关系 |
