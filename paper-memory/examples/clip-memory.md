# Learning Transferable Visual Models From Natural Language Supervision (CLIP)
> **作者**: Alec Radford, Jong Wook Kim, et al. | **发表**: ICML 2021 | **链接**: arXiv:2103.00020


# 一句话记忆
CLIP 通过在大规模互联网图文对数据集 (WIT-400M) 上，使用对称双塔对比学习目标对齐图像与文本编码器，实现了无需微调即可泛化到多任务的零样本图像分类与跨模态检索。

# 研究问题

## 以前的方法
传统的视觉模型（如 ResNet, EfficientNet）主要在固定类别标签集（如 ImageNet-1k）上，利用交叉熵损失进行监督学习。

## 存在的问题
- **泛化能力差**：遇到训练集类别之外的物体时（如 OOD 域外数据），模型性能发生显著下降。
- **标注昂贵且受限**：人工标注海量精准的单标签分类数据成本极高，且固定类别极大限制了模型对开放世界的理解。
- **任务隔离**：为某个分类任务训练的模型无法直接用于另一个定位或分割任务，模型参数无法零样本迁移。

## 论文试图解决什么
利用廉价且极易获取的自然语言文本作为直接监督信号，训练一个具有强鲁棒性、开放世界理解能力，并且能“零样本” (Zero-Shot) 泛化到各种下游视觉任务的多模态通用模型。

# 核心洞察
1. **研究洞察**：自然语言包含极其丰富、多维度的语义描述，将其作为监督信号而非离散的数字 ID，能极大地提升模型的开放语义理解上限。
2. **工程实现**：相比于自回归生成模式（如图像转文本），在大规模嘈杂图文对上使用“对比学习” (Contrastive Learning) 来预测哪些图文对匹配，不仅训练吞吐量提高了 4-10 倍，泛化能力也更为优越。
3. **普通组件**：底座使用标准的 ResNet50/ViT 作为图像编码器，标准的 Transformer 解码器（无因果 Mask）作为文本编码器。

# 关键模块

- **模块名称**：Image Encoder (图像编码器)
  - **输入**：`[Batch_Size, 3, H, W]` 维图像张量。
  - **输出**：`[Batch_Size, D_i]` 维图像表示特征。
  - **作用**：将原始像素提取为密集的全局语义特征。
  - **为什么需要**：作为双塔的一侧，将图像信号压缩为向量表示。
  - **去掉后可能发生什么**：无法处理视觉信号，对比学习无法发生。

- **模块名称**：Text Encoder (文本编码器)
  - **输入**：`[Batch_Size, Sequence_Length]` 维文本 Token 序列。
  - **输出**：`[Batch_Size, D_t]` 维文本表示特征。
  - **作用**：提取句子中的语言学语义，并对齐最后一个 Token 的特征作为全局向量。
  - **为什么需要**：将高维文本序列压缩为语义空间向量。
  - **去掉后可能发生什么**：无法接入语言监督，退化为普通图像无监督对比学习（如 SimCLR）。

# 训练目标或核心公式
CLIP 的核心损失是基于多类 N-Pair 的对称信息瓶颈噪声对比估计损失 (Symmetric InfoNCE Loss)：

对于一个大小为 $N$ 的 batch 中的第 $i$ 个图文对，设其图像 L2 归一化特征为 $I_i$，文本 L2 归一化特征为 $T_i$，可学习的温度参数为 $\tau$。

图像到文本的对比损失（行交叉熵）：
\[\mathcal{L}_{I \to T}^{(i)} = -\log \frac{\exp(I_i \cdot T_i \cdot e^\tau)}{\sum_{j=1}^N \exp(I_i \cdot T_j \cdot e^\tau)}\]

文本到图像的对比损失（列交叉熵）：
\[\mathcal{L}_{T \to I}^{(i)} = -\log \frac{\exp(T_i \cdot I_i \cdot e^\tau)}{\sum_{j=1}^N \exp(T_i \cdot I_j \cdot e^\tau)}\]

最终总损失：
\[\mathcal{L} = \frac{1}{2N} \sum_{i=1}^N \left( \mathcal{L}_{I \to T}^{(i)} + \mathcal{L}_{T \to I}^{(i)} \right)\]

- **优化目标**：极大化同对（正样本）图像与文本的相似度，极小化非同对（负样本）图像与文本的相似度。
- **正样本**：配对的真实图文对 $(I_i, T_i)$。
- **负样本**：当前 batch 内其他 $N-1$ 对图文。
- **关键变量**：$\tau$（控制分类概率的分布平滑度，随训练自适应学习）。
- **对模型行为的影响**：使模型能拉近匹配的多模态概念，推开不匹配的概念，实现视觉和文本在语义维度的无缝平移。

# 实验证明了什么

- **实验问题**：CLIP 的零样本 (Zero-shot) 分类能力能否比肩有监督模型？
- **比较对象**：完全有监督训练的 ResNet50 baseline 模型。
- **观察结果**：在 ImageNet-1k 零样本评估中，基于 ViT-L 的 CLIP 取得了 76.2% 的准确率，表现与全监督 ResNet50 基本相当，但在域外测试集（如 ImageNet-A, ImageNet-R, ImageNet-Sketch）上准确率远超 ResNet50（CLIP 的表现下滑非常轻微，而 ResNet50 下滑了 30-40%）。
- **支持的结论**：
  - 基于大规模自然语言弱监督预训练的模型具有极强的泛化鲁棒性，克服了传统监督模型的域偏移问题。
- **不能支持的结论**：
  - CLIP 在极其细粒度或专业化任务（如区分花卉的具体品种、识别卫星图像中的细微道路、计算目标数量等）上直接进行零样本推理的性能依然较弱，仍需要任务特定的监督微调。

# 局限与失效场景
- **局限**：对“几何、空间方位（如左、右、上、下）”和“复杂数量（如 3 个苹果 vs 4 个苹果）”的理解极为薄弱。
- **产生原因**：WIT-400M 预训练语料主要是包含语义名词的标题描述，很少包含精细几何定位或计数词汇的密集关联。
- **可能失败的场景**：给定包含“一个大正方形在小圆圈左边”的图像，CLIP 极易将其预测为“一个小圆圈在大正方形左边”。
- **对后续研究的意义**：促使后续工作（如 GLIP、BLIP 等）引入细粒度检测框或几何关系对齐损失。

# 与其他论文的关系

## 前置基础
- [[Transformer]]：提供了用于文本和图像（ViT）的主干特征提取网络。

## 同任务工作
- [[ALIGN-2021]]：与 CLIP 几乎同时发布，同样在大规模嘈杂图文对 (1.8B) 上进行多模态对比预训练，但使用了不同的图像/文本主干。

## 思想相似
- [[SimCLR]]：图像内部的对比学习，CLIP 将其推广到了图像-文本的跨模态对比。

## 后续改进
- [[BLIP]]：为了改进 CLIP 对嘈杂互联网文本的依赖，提出清洗文本并结合生成损失，提供了更强的多模态生成和理解能力。
- [[DenseCLIP]]：将 CLIP 从全局图文对齐扩展到区域和密集像素对齐，以支持分割与检测任务。

## 关键差异
- 与 [[DINOv2]] 相比，DINOv2 采用自监督特征蒸馏（完全不需要文本），保留了更强的细粒度几何和局部稠密特征，而 CLIP 更偏向宏观的高维语义映射。

# 对我的课题的启发
- 在我们的多模态大模型定位课题中，可以直接复用预训练好的 CLIP 视觉编码器，但必须注意它可能丢失局部细粒度几何坐标的缺陷，建议结合其他几何特征提取器（如 DINOv2 或 PointNet）。
