# 复习会话模板

在管理交互式主动回忆会话时使用此模板。

```markdown
# 论文复习会话: [论文名称或按 profile 渲染的链接]
**日期**: YYYY-MM-DD
**用户水平**: [初学者 / 中级 / 高级]

---

- **用户回答**: ...
- **AI 反馈**:

- **用户回答**: ...
- **AI 反馈**:
```
