# 格式转换指南

本文档提供图片元素到 Markdown 的详细格式对照和转换示例。

## 格式对照表

| 图片中的元素 | Markdown 表示 |
|-------------|--------------|
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 三级标题 | `### 标题` |
| 粗体文字 | `**文字**` |
| 斜体文字 | `*文字*` |
| 无序列表 | `- 项目` |
| 有序列表 | `1. 项目` |
| 表格 | `\| 列1 \| 列2 \|` |
| 代码块 | ` ```语言\n代码\n``` ` |
| 引用 | `> 内容` |

## 转换示例

### 示例 1：纯文字文档

**图片内容：**
```
会议记录

时间：2024年1月15日
参与人：张三、李四、王五

议程：
1. 上季度总结
2. 下季度计划
3. 预算讨论
```

**正确输出：**
```markdown
# 会议记录

时间：2024年1月15日
参与人：张三、李四、王五

议程：
1. 上季度总结
2. 下季度计划
3. 预算讨论
```

> 注意：图片中"议程："后面虽然没有列表标记，但如果视觉上能看出是列表结构，可以添加 Markdown 列表格式。但如果原文就是纯文本排列，则保持原样，不要擅自添加列表标记。

### 示例 2：包含表格的图片

**图片内容：** 销售数据表格

**正确输出：**
```markdown
| 产品 | Q1销量 | Q2销量 |
|------|--------|--------|
| 产品A | 100 | 150 |
| 产品B | 80 | 120 |
```

**错误输出（不要这样做）：**
```markdown
图片显示了一个销售数据表格，包含产品A和产品B的销量数据。
```

### 示例 3：流程图

**图片内容：** 三步流程图

**正确输出：**
```markdown
1. 开始
2. 处理
3. 结束
```

### 示例 4：纯照片

**图片内容：** 风景照片，无文字

**正确输出：**
```markdown
# 图片内容

> [无法转换为 Markdown 的内容]
> 一张风景照片，显示山脉和湖泊的景色。
```

### 示例 5：包含代码的图片

**图片内容：** 代码截图

**正确输出：**
````markdown
```python
def hello():
    print("Hello, World!")
```
````

### 示例 6：混合内容（文字 + 图表）

**图片内容：** 一页 PPT，包含标题、正文段落和一个柱状图

**正确输出：**
```markdown
# 季度业绩汇报

本季度销售额同比增长 25%，主要增长来自华东地区。

## 销售数据

| 地区 | 销售额（万元） | 同比增长 |
|------|--------------|---------|
| 华东 | 500 | 35% |
| 华北 | 320 | 18% |
| 华南 | 280 | 22% |
```
