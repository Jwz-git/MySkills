# Markdown 格式转换指南

仅在版面不止普通段落时读取本文件。格式化的作用是保存原图结构，不是重新编辑内容。

## 基本映射

| 原图结构 | Markdown 表示 | 边界 |
|---|---|---|
| 标题 | `#`、`##`、`###` | 只按明确的字号、位置和层级关系判断 |
| 粗体/斜体 | `**文字**`、`*文字*` | 无法确认字形时保留普通文本 |
| 列表 | `-` 或 `1.` | 视觉上明确为列表时才添加标记 |
| 引用 | `> 内容` | 不把普通缩进误作引用 |
| 表格 | GFM Markdown 表格 | 单元格归属必须可确认 |
| 代码 | 围栏代码块 | 保留大小写、空格、缩进和符号 |
| 公式 | `$...$` / `$$...$$` | 仅在符号可可靠辨认时转写 |
| 分隔线 | `---` | 仅保留有语义的章节/页面分隔 |

## 表格

转录明确的行列关系，并转义单元格内的 `|`。单元格换行可用 `<br>`；合并单元格无法忠实表示时，优先使用 HTML 表格，或线性转录并说明结构不确定。

```markdown
| 产品 | Q1 销量 | Q2 销量 |
|---|---:|---:|
| 产品 A | 100 | 150 |
| 产品 B | 80 | 120 |
```

不要把表格改写成“图片显示了一个销售表格”。也不要为了凑齐列数而补空值之外的内容。

## 代码

选择能从截图明确判断的语言标签；不确定时使用无语言标签的围栏。保留行号以外的所有代码字符。行号是编辑器装饰时通常忽略；若代码或讨论引用行号则保留。

````markdown
```python
def hello():
    print("Hello, World!")
```
````

不要修复截图中的语法错误，也不要展开被折叠或截断的代码。

## 公式

可靠辨认时使用 LaTeX：

```markdown
$$
E = mc^2
$$
```

只要关键上下标、运算符或矩阵边界无法确认，就裁剪公式区域并嵌入图片；不要输出“看起来可能是”的 LaTeX。

## 图表

按以下顺序保存信息：

1. 转录标题、轴标题、刻度、图例、数据标签和脚注；
2. 只有数值被明确打印或可无歧义读取时，才整理为数据表；
3. 若几何形状、趋势或颜色编码本身有意义，嵌入图表裁剪图；
4. 不从柱高、折线位置、气泡面积或饼图角度估算未标出的值。

示例：只有图中明确标注 `华东 500`、`华北 320` 时，才可输出：

```markdown
| 地区 | 销售额（万元） |
|---|---:|
| 华东 | 500 |
| 华北 | 320 |

![销售额柱状图](img/sales-chart.png)
```

## 流程图与组织结构图

- 简单、单一路径流程：用编号列表和箭头文字转录。
- 分支、回路或跨层连接较复杂：嵌入裁剪图，并在旁边只列出可确认的节点和边。
- 组织结构层级明确时用嵌套列表；虚线汇报关系或多人共享节点无法准确线性化时保留图片。

## 混合版面

按人类正常阅读顺序排列，不按 OCR 碰巧返回的顺序。双栏页面通常先完整读取左栏再读右栏；若有跨栏标题，先输出标题。侧边注释插入与其锚点最接近的位置；无法判断锚点时在相邻段落后标记为“旁注”。

## 非文本视觉元素

签名、印章、照片、手绘图、复杂示意图等若对原文有意义，应裁剪并嵌入。替代文本只做客观识别，例如 `![手写签名](img/signature.png)`；不要根据外观推断身份、意图或真实性。
